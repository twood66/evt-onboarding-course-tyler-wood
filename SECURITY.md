# Security and privacy

Do not open a public issue containing:

- GitHub tokens or authentication codes
- Passwords or private keys
- Private repository contents
- Student records or personal contact information
- Vehicle logs that have not been approved for public release

The setup report is designed to contain only an operating-system label, course
mode, generation time, boolean checks, and a completion result. Review it before
committing.

If a secret was committed, revoke or rotate it immediately. Deleting the file
from the newest commit does not remove it from Git history.

Report a course bug through the public Course help form only when the report and
screenshots contain no sensitive information. Send security-sensitive reports
to a KSU EVT owner through the team's approved private channel.

# Lesson 2: Git and GitHub practice

This lesson uses the public
[`github-practice`](https://github.com/KSU-Electric-Vehicle-Team/github-practice)
repository.

The planned exercise covers:

- Forking a public repository
- Cloning the fork
- Creating and switching branches
- Editing and committing a file
- Publishing a branch
- Opening a draft pull request
- Reading an automated check
- Responding to review
- Updating the pull request

Students do not need organization membership. The existing repository checker
validates the submitted practice file. This lesson will later add a course
progress record that verifies the public pull request URL.

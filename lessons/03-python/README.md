# Lesson 3: Python telemetry practice

This lesson will teach students to read a small CSV telemetry fixture, validate
its fields, calculate summary values, and test failure cases.

The exercise will use local unit tests and the same tests in GitHub Actions. It
will not require private vehicle data, external services, notebooks, or secrets.

Planned completion evidence:

- The parser rejects malformed rows.
- The summary calculation passes the supplied tests.
- The student explains one failure case in plain language.
- The GitHub check passes.
